# خادم إشعارات Telegram — مزرعتي قطر

خدمة مستقلة تراقب جدول `mawashi_orders` في PostgreSQL/Neon وترسل كل طلب جديد إلى محادثة Telegram. لا تغيّر هذه الخدمة منطق الموقع أو خادم API الحالي، ولا تخزّن رقم البطاقة أو CVV أو أي بيانات دفع حساسة.

## المتغيرات المطلوبة

```env
DATABASE_URL=postgresql://...
TELEGRAM_BOT_TOKEN=ضع_رمز_البوت_هنا
TELEGRAM_CHAT_ID=ضع_معرف_المحادثة_هنا
PORT=8787
POLL_INTERVAL_MS=10000
```

ضع المتغيرات في إعدادات الاستضافة، ولا تضعها داخل Git أو ملفات الواجهة. الخدمة تنشئ جدول `mawashi_telegram_notifications` تلقائياً، وتستخدمه لمنع إرسال الطلب نفسه أكثر من مرة.

## التشغيل

```bash
npm install
npm start
```

فحص الصحة متاح عبر `GET /healthz`. الخدمة ترسل بيانات الطلب الأساسية فقط: رقم الطلب، المنتج، الكمية، العميل، رقم التواصل، العنوان، موعد التوصيل، وطريقة/حالة الدفع.

## ملاحظات النشر

هذه خدمة عاملة باستمرار، لذلك يجب نشرها على استضافة تدعم Worker أو خدمة Node طويلة التشغيل، مع إبقاء `DATABASE_URL` وبيانات Telegram كأسرار server-side. لا تستخدم Web Worker أو كود المتصفح لإرسال الرمز.
